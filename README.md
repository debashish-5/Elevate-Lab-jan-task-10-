
# MNIST Digit Classification - Elevate Lab Task 10

This repository contains the implementation and documentation for **Task 10** of the Elevate Lab Internship Program. The project focuses on training and evaluating Machine Learning / Deep Learning models on the classic **MNIST Handwritten Digit Dataset**.

---

## 📌 Project Overview

The objective of this task is to build a classification pipeline capable of accurately identifying handwritten digits (0–9) using the MNIST dataset. 

### Key Features
- **Data Preprocessing**: Normalization and reshaped input feature vectors.
- **Model Training**: Implementation of classification algorithms (e.g., Multi-Layer Perceptron / Convolutional Neural Network / Scikit-Learn Classifiers).
- **Evaluation**: Accuracy metrics, confusion matrix, and performance analysis.

## 📊 Dataset Details

The **MNIST** dataset consists of 70,000 grayscale images of handwritten digits:

* **Training set**: 60,000 images
* **Test set**: 10,000 images
* **Image dimensions**: 28x28 pixels
